# 🔐 Sistema de Login - Python + SQLite

Sistema simples de cadastro e login feito em Python com banco de dados SQLite. Projeto ideal para portfólio iniciante.

## 🚀 Funcionalidades

- ✅ Criar conta com login único
- ✅ Validação de login existente
- ✅ Sistema de login com verificação
- ✅ Banco de dados SQLite persistente
- ✅ Tratamento de erros

## 🛠️ Tecnologias

- Python 3
- SQLite3 (nativo do Python)
- Git
